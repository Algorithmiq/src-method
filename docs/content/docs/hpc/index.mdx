title: HPC clusters
description: Set up and run src_method on supercomputers, with an example job script for each.
---

`src_method` needs nothing cluster-specific: a Python environment with the
[GPU extra](/features/gpu), and on a node with several GPUs,
`Resources(devices=n)` (see [Large problems](/features/large-problems#several-gpus)).
What changes between clusters is the driver, the storage and the scheduler. Each
page below collects what we needed on one machine.
