The SRC algorithm for the compressed MPO-MPS product is introduced in
[@camano2026src]; `src_method` extends it to MPO-MPO products, plain compression
and stacks of trains. It builds on the randomized range finder of
[@halko2011finding]. The array layout follows `quimb` [@gray2018quimb], which the
tests and tutorials also use to build reference networks.
