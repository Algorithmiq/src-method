---
title: Adaptive truncation
description: Trim bonds below chi_out with a relative singular-value cutoff.
---

`chi_out` is the maximum output bond dimension. Set `cutoff` to trim each bond
further using a relative singular-value threshold:

```python
import quimb.tensor as qtn

from src_method import apply

H = qtn.MPO_identity(8, phys_dim=2)
psi = qtn.MPS_rand_state(8, bond_dim=4, seed=0)

fixed = apply(H.arrays, psi.arrays, chi_out=32, seed=1)
trimmed = apply(H.arrays, psi.arrays, chi_out=32, cutoff=1e-10, seed=1)

print([a.shape[0] for a in fixed[1:]])
print([a.shape[0] for a in trimmed[1:]])
```

By default, `apply`, `compress` and `src` use sketch size
`max(ceil(1.5 * chi_out), chi_out + 10)`, following the original paper's
oversampling recommendation. A final left-to-right SVD sweep truncates the
right-canonical sketch to `chi_out`, discarding singular values below
`cutoff * sigma_max` at each cut. These are the Schmidt values of the intermediate
train as truncated so far, not of the random sketch matrix. The result is
**left-canonical**, with the norm on the last site. Each cut is truncated optimally
for the train as truncated so far; the discarded weights add in quadrature.

Set `oversample` to a finite multiplicative factor of at least `1.0` to use sketch
size `ceil(oversample * chi_out)`. Larger sketches cost more time and memory.
`oversample=1.0` disables oversampling and the final SVD pass, recovering the
original **right-canonical** output. In that mode, `cutoff` acts on the sketch's
QR triangular factor during the right-to-left sweep, not on Schmidt values.

- `cutoff` must lie in `[0.0, 1.0)`; `0.0` (the default) disables trimming.
- `chi_out` remains the upper bound: the cutoff only ever lowers a bond.
- Two-site trains use the exact fallback, which ignores `cutoff` and truncates to
  `chi_out`, returning right-canonical output regardless of `oversample`.
